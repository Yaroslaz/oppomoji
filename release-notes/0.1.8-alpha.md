**Срочное исправление 0.1.7: в объединённом файле не было видно букв.** Если ты поставил `OPPOMoji-iOS-<жирность>.ttf` из 0.1.7, верни текст. Настройки → Дополнительные настройки → Язык и регион, выключи «Поддержка символов Dai» (нижний переключатель во второй карточке). Затем верни стандартный шрифт в zFont.

**Почему так вышло.** Рендерер Android (Skia поверх FreeType) не рисует контуры букв из шрифта, в котором есть цветные картинки CBDT, и выводит только картинки. Поэтому в файле OPPO Sans + iOS-эмодзи буквы были невидимы, а эмодзи видны. Тест 0.1.7 проверял, из какого файла берётся глиф, но не проверял, что он видим. Значит, OPPO Sans и iOS-эмодзи в одном файле на Android невозможны. Через слот Dai на этой прошивке доступен один из двух вариантов.

**iOS-эмодзи для Dai** (`OPPOMoji-iOS-Dai.ttf`, кнопка «Подготовить iOS-эмодзи для zFont»):
- полный набор Emoji 17.0 без своих пробела, цифр, `#`, `*`, знаков препинания, ©, ®, ™ и стрелок;
- эти символы и буквы рисует следующий шрифт ColorOS в цепочке — Roboto с осью веса, поэтому жирный текст работает;
- ©️, 1️⃣ и #️⃣ остаются картинками через `cmap` формата 14, а ©, 1 и # — обычными символами;
- цифры больше не превращаются в эмодзи, пробелы нормальной ширины.

**OPPO Sans нужной жирности** (`OPPOMoji-OPPOSans-<жирность>.ttf`, кнопка «Сохранить OPPO Sans для zFont»):
- статический OPPO Sans с вшитой жирностью;
- эмодзи остаются системными.

**Проверка видимости.** После сборки приложение рисует пробные символы через «файл слота, затем системные шрифты», как это делает Dai. Пиксели считаются по-настоящему. Буквы, цифры, точка, запятая и © должны быть видимы и не из эмодзи-файла. ©️, 1️⃣, ❤️‍🔥 и 🙂‍↕️ должны быть видимы и из него. Если проверка не прошла, файл не сохраняется. Тест на эмуляторе Android 16 проверяет то же самое, а для OPPO Sans сверяет ширину текста с Roboto, который Android рендерит с вариацией `wght` 700.

Устанавливается поверх 0.1.7-alpha. Проверка на настоящей ColorOS ещё необходима. Пришли отчёт после применения: он покажет, каким файлом рисуются буквы, цифры, точка и пробел.
