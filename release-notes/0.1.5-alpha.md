Главное в этой версии — подготовка iOS-эмодзи для zFont одной кнопкой. Первая карточка показывает образец эмодзи с текущими файлами и чек-лист: OPPO Sans → iOS-набор → линия подчёркивания → файл для zFont. Кнопка «Подготовить iOS-эмодзи для zFont» проходит эти шаги подряд и пропускает уже готовые. Она находит OPPO Sans с кириллицей и загружает закреплённый набор Emoji 17.0 с проверкой SHA-256. Затем переносит линию подчёркивания из OPPO Sans и сохраняет `Загрузки/OPPOMoji/OPPOMoji-iOS-emoji.ttf`. Этот файл импортируется в zFont тем способом, который уже работает на телефоне.

- Строка статуса с полосой загрузки закреплена внизу экрана и видна при прокрутке. Редкие экспорты собраны в «Дополнительно».
- Исправленные копии пересобираются только при смене исходного файла или ползунков линии. Раньше изменение веса предпросмотра каждый раз переписывало 35 МБ.
- В 0.1.4 падала проверка Emoji 17.0 на Android 16. ©️ ®️ ‼️ ⁉️ ™️ #️⃣ 1️⃣ в предпросмотре рисовались текстовым шрифтом. Причина не в наборе. Приложение не может пометить свой emoji-шрифт как системное emoji-семейство (`und-Zsye`), поэтому символ, который есть в текстовом шрифте, остаётся у него. Системное emoji-семейство такие символы забирает. Проверка теперь проверяет эти последовательности на самом файле, а предпросмотр поясняет ограничение.
- Отчёт показывает `claimsEmojiPresentation`: объявляет ли выбранный OPPO Sans сам ©️ и другие последовательности с U+FE0F. Такой основной шрифт оставил бы их текстом и в системе.

Требует проверки на Reno 16 Pro: в этом наборе пробел, цифры, `#` и `*` имеют ширину 1,25 em, как во всех шрифтах на структуре Noto. Если при включённом Dai emoji-шрифт стоит в системе первым, такие пробелы и цифры могут появиться во всей системе. Пришли отчёт и снимок экрана, если это заметно.

Устанавливается поверх 0.1.3-alpha с сохранением локальных шрифтов и настроек. Шрифты Apple/OPPO в APK не включены; набор загружается только по кнопке. Системный шрифт приложение не меняет — это делает zFont.

Проверено в CI: JVM-тесты редактора, Android Lint и инструментальные тесты на эмуляторе Android 16. Среди них сценарий в одно нажатие без окна выбора файла и все 3 953 последовательности Emoji 17.0. Проверка на настоящей ColorOS ещё необходима.
